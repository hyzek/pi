# Old Flux work

source snapshots. They describe work on the archived Flux fork, not the current
repository state or the proposals in [`../additions/`](../additions/).

- [`work.md`](work.md): concise inventory of the old Flux fork and caveats.
- [`flux.md`](flux.md), [`harness-plan.md`](harness-plan.md), and
  [`inputbox.md`](inputbox.md): detailed historical product and implementation notes.
- [`export.md`](export.md) and [`export/`](export/): commit inventory and complete
  snapshots of the archived Flux changes.
